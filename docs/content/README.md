# Internal project research

This directory contains working material for future portfolio content. It is maintainer-only source material, not published copy and not an authoritative record of client work.

- `projects-inventory.md` preserves the broader project list and repository links used during the homepage consolidation.
- `project-blog-drafts.md` contains possible long-form case-study starting points assembled from repository evidence and explicit placeholders.

Before publishing any passage, verify the repository is the intended project, the implementation still matches the description, the stated role and team shape are accurate, metrics can be substantiated, and screenshots or client details are cleared for public use. Prefer the current project repository and direct knowledge over these drafts when they disagree.
